## OSINT

!!! tip "Use OSINT Framework"
	[OSINT Framework](https://osintframework.com) lists a handful of useful OSINT tools depending on the task.

### Technical OSINT

Technical OSINT consists in passively finding information about anything related to the target's infrastructure, let it be webserver's version, whether or not a vulnerability was scanned, old DNS records, et cetera.

| Website name                                                       | Description                                                                              | Access | Rating |
| ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------- | :----: | :----: |
| [Archive](https://web.archive.org)                                 | Web archive. If the desired page was archived, then the content will be available there. |   🟢   |   ✨    |
| [BuiltWith](https://builtwith.com)                                 | Gives out the frameworks that were used to create a website.                             |   🟢   |   ✅    |
| [Censys](https://platform.censys.io/home)                          | Endpoint research with filters **with** vulnerability research.                          |   🟢   |   ✨    |
| [CriminalIP](https://search.criminalip.io)                         | Endpoint research with filters.                                                          |   🟡   |   ❔    |
| [CRT](https://crt.sh)                                              | Certificate research.                                                                    |   🟢   |   ➖    |
| [DNSDumpster](https://dnsdumpster.com)                             | DNS reconnaissance.                                                                      |   🟢   |   ✅    |
| [DorkSearch](https://dorksearch.com)                               | Dork research across different web browsers.                                             |   🟢   |   ➖    |
| [Google Dorks](https://www.exploit-db.com/google-hacking-database) | Lists known google dorks.                                                                |   🟢   |   ✅    |
| [Grep](https://grep.app)                                           | Code snippets research.                                                                  |   🟢   |   ✨    |
| [GreyNoise](https://viz.greynoise.io)                              | IP, uptime and CVE scanner.                                                              |   🟡   |   ❔    |
| [LeakIX](https://leakix.net)                                       | Endpoint research with filters.                                                          |   ✅    |   ✨    |
| [Netcraft](https://sitereport.netcraft.com)                        | Deep domain name research and server information gathering.                              |   🟢   |   ✅    |
| [Onyphe](https://search.onyphe.io)                                 | Domain name information gatherer.                                                        |   🟢   |   ✨    |
| [PublicWWW](https://publicwww.com)                                 | Online HTML/CSS/JS code snippet research.                                                |   🟡   |   ➖    |
| [Shodan](https://www.shodan.io)                                    | Endpoint research with filters.                                                          |   🟡   |   ✅    |
| [WhoIs](https://who.is)                                            | Well-known global website scanner.                                                       |   🟢   |   ✨    |
| [Wigle](https://wigle.net)                                         | WiFi reconnaissance. Be careful to not zoom out, or you will quickly run out of quota !  |   🟢   |   ➖    |

### Identity OSINT

Identity OSINT is the art of crossing pieces of information together to track an organization, or a single person.

| Website name                                 | Description                                                                       | Access | Rating |
| -------------------------------------------- | --------------------------------------------------------------------------------- | :----: | :----: |
| [Epios](https://epios.com)                   | Email and phone OSINT platform.                                                   |   🟢   |   ✅    |
| [Facecheck](https://facecheck.id)            | Face recognition done on social medias.                                           |   🟢   |   ❔    |
| [Hunter](https://hunter.io)                  | Finds email formats issued by a company.                                          |   🟠   |   ❔    |
| [Lampyre](https://lampyre.io)                | Centralizes and links accounts together.                                          |   🔴   |   ❔    |
| [Maltego](https://www.maltego.com)           | Centralizes and links accounts together.                                          |   🟠   |   ❔    |
| [Namechk](https://namechk.com)               | Verifies the availability of a username on different platforms.                   |   🟢   |   ✅    |
| [OSINT.industries](https://osint.industries) | Global identity OSINT platform.                                                   |   🔴   |   ❔    |
| [OSINT.ly](https://osint.ly)                 | Global identity OSINT platform.                                                   |   🟠   |   ✨    |
| [Phonebook](https://phonebook.cz)            | Despite the name, email addresses linked to a domain. Requires an intelx account. |   🟠   |   ❔    |
| [Social Searcher](https://phonebook.cz)      | Basic page finder based on username.                                              |   🟢   |   ❌    |
| [SpiderFoot](https://spiderfoot.tools)       | Username, email and IP address search engine.                                     |   🟢   |   ✨    |
| [TinEye](https://tineye.com)                 | Inverse image search specialized in finding the base image of photoshopped ones.  |   🟢   |   ❔    |
| [WhatsMyName](https://whatsmyname.app)       | Recherche par username.                                                           |   🟢   |   ➖    |
